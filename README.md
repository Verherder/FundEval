# FundEval - 基金交易与收益评估工具

FundEval 参考LanFund继续演进，定位为“可交易记录、可收益评估、可视化对比”的基金工具。
支持终端和 Web 两种使用方式，默认通过 Web 页面（8311 端口）进行日常操作。

---

## ✨ 最新功能

- 🧾 **交易闭环**：支持买入、卖出、补录交易
- 📈 **收益升级**：支持持有收益 + 年化收益双指标
- ⏱️ **净值确认规则**：买入按净值日确认份额（15:00 前后区分）
- 🧭 **业绩对照**：基金业绩曲线叠加沪深300基准
- 🔵🔴 **交易点可视化**：业绩图展示买入/卖出点位
- 🏷️ **持仓管理增强**：星标、份额、板块、导入导出联动

---

## 功能特性

### 交易与持仓

- 买入基金（按金额）
- 卖出基金（按份额）
- 补录历史买入（指定日期/净值/金额）
- 持仓份额管理（手动设置/修改）
- 持有标记与份额状态联动

### 收益评估

- 持有收益（实时展示）
- 年化收益（实时展示）
- 刷新后统一重算持仓统计

### 图表与可视化

- 基金估值趋势图
- 基金业绩曲线（支持区间切换）
- 沪深300对照曲线
- 买入/卖出交易点叠加显示
- 图中展示最新净值与净值日期

### 基础数据能力

- 基金增删改查
- 板块标注/取消
- 导入导出基金列表
- 持仓统计面板与一键炫耀卡片

## 💡 使用建议

**推荐工作流程**：

1. **Web 端首次配置**
   - 访问 `http://localhost:8311` 注册/登录
   - 添加基金、设置份额、标记持有、配置板块

2. **日常操作**
   - 优先在 Web 端进行买入/卖出/补录与收益查看
   - 按需导出基金列表用于备份或迁移

3. **CLI 用户同步配置**
   ```bash
   # 将导出的 fund_map.json 复制到 cache 目录
   cp fund_map.json cache/fund_map.json

   # 之后可在 CLI 模式下使用
   python fund.py
   ```

## 使用方法

### 命令行模式

#### 查看所有信息

```bash
python fund.py
```

显示内容包括：

- 7×24快讯
- 行业板块排行
- 实时金价
- 黄金历史价格
- 近7日A股成交量
- 近30分钟上证指数
- 市场指数汇总
- 预估收益
- 自选基金估值

#### 管理自选基金

**添加基金**

```bash
python fund.py -a
```

**删除基金**

```bash
python fund.py -d
```

**标记持有基金**

```bash
python fund.py -c
```

**取消持有标记**

```bash
python fund.py -b
```

**标记基金板块**

```bash
python fund.py -e
```

**删除板块标记**

```bash
python fund.py -u
```

**查询基金板块**

```bash
python fund.py -s
```

**修改基金持仓份额**

```bash
python fund.py -m
```

### AI 分析命令

```bash
python fund.py -W
python fund.py -f -W
python fund.py -D -W
```

### Web 服务器模式

#### 启动服务

```bash
python fund_server.py
```

默认地址：`http://localhost:8311/portfolio`

#### Web 操作功能

- 添加/删除基金
- 买入/卖出/补录交易
- 标记持有与设置份额
- 标注板块
- 导入导出基金列表
- 查看收益与业绩图
